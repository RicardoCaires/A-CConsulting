# Shootingliste — Pflichtpositionen

4 Positionen. Ein Termin. Ohne diese vier geht die neue Gestaltung nicht.

---

## Vorher

- Büro aufräumen, freie Wandfläche und Fensterlicht suchen
- Keine echten Namen, Beträge, Policen- oder AHV-Nummern im Bild —
  auch nicht unscharf auf einem Bildschirm
- Beide gleich gekleidet im Register: Hemd, kein Sakko-Bruch zwischen den zweien
- RAW mitspeichern
- Freigabe schriftlich, auch von euch selbst

---

## 1 · Hero quer

| | |
|---|---|
| Motiv | Ricardo **oder** Octavio, halbnah, im Büro oder auf dem Weg dorthin |
| Format | **16:9** quer |
| Auflösung | **min. 3000 × 1688 px** |

- Blick **nicht** in die Kamera — arbeitend, telefonierend, im Gespräch
- Tageslicht, kein Blitz
- **Eine Bildhälfte ruhig lassen** (Wand, Fenster, Unschärfe) — dort steht später die Überschrift
- Person aus der Mitte gerückt, nicht zentriert
- Hoch- und Querformat vom **selben Moment**, nicht nachgestellt

## 2 · Hero hoch

| | |
|---|---|
| Motiv | dasselbe wie 1 |
| Format | **4:5** hoch |
| Auflösung | **min. 2000 × 2500 px** |

- **Eigene Aufnahme, nicht aus dem Querformat geschnitten** — sonst fehlt oben oder unten
- Ruhige Fläche diesmal **oben**, nicht seitlich
- Direkt nach 1 aufnehmen, gleiches Licht

## 3 · Porträt Ricardo

| | |
|---|---|
| Motiv | Brustbild, neutraler Hintergrund oder Büro unscharf |
| Format | **3:4** hoch |
| Auflösung | **min. 1500 × 2000 px** |

- Blick in die Kamera, freundlich, nicht lachend
- Augen auf oberem Bilddrittel
- Schultern leicht angewinkelt, nicht frontal

## 4 · Porträt Octavio

| | |
|---|---|
| Motiv | wie 3 |
| Format | **3:4** hoch |
| Auflösung | **min. 1500 × 2000 px** |

- **Gleicher Ausschnitt, gleiche Distanz, gleiche Höhe, gleiches Licht wie 3**
- Direkt nacheinander aufnehmen, Kamera nicht bewegen
- Sonst stehen die beiden Karten nebeneinander und wirken ungleich
